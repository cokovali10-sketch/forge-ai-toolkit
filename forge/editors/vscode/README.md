# FORGE Pipe — VS Code extension (scaffold)

Запуск конвейера из редактора: команда **«FORGE: прогнать конвейер»**,
находки ревью падают в панель Problems с переходами по строкам,
статус виден в статус-баре.

Статус: **скелет, не проверено** — нужен Node.js (`npm install -g @vscode/vsce`
и `vsce package` из этой папки). JS не запускался в этой среде, это честно
указано здесь, а не заметено под ковёр.

Схема диагностики повторяет формат `pipe run --json` (см. `src/forge/pipe/sarif.py
и отчёты раннера), так что бэкенд уже готов и покрыт тестами.
